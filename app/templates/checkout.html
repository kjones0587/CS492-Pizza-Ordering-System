Security & Payment Data Privacy
Simulated PCI-DSS Level 1 Sandbox Environment This senior capstone project strictly adheres to modern payment industry security standards and OWASP Top 10 guidelines.
Our Security Commitments:
  • Zero Plain-Text Storage: Credit card numbers (PAN) and CVV security codes are never stored in databases, logs, or cookies.
  • Algorithmic Validation: Card numbers undergo strict Modulo 10 Luhn checksum verification prior to transmission.
  • Session Hardening: All HTTP transactions utilize cryptographically signed session cookies with HTTPOnly and SameSite=Lax flags.
  • CSRF Protection: Cross-Site Request Forgery tokens protect all state-changing actions across the application.
Audit Trail: Only sanitized gateway reference IDs (e.g. TXN-...), card brand, and masked last 4 digits are recorded on order receipts for customer verification.
